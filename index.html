Project concept

What this dashboard simulates

Production RAG systems need more than a chat interface. They require retrieval metrics, grounded answer checks, citation coverage, latency/cost tracking, and trace-level debugging. This static app visualizes those artifacts as if they were generated by an offline LLMOps evaluation pipeline.

Why this is GitHub Pages friendly

No live backend

The deployed dashboard reads static JSON files. No API key, model server, database, or paid hosting is needed.

Offline evaluation pipeline

Python scripts generate RAG traces, metrics, and model-card style summaries before deployment.

Recruiter signal
